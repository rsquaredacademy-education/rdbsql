4.2 Set Up

In order to be able to use the ecom data set for our case study, we will read it using the readr package and then copy it to an in memory database using the copy_to() function from dplyr.

# Canonical ecom: 1000 rows x 8 cols (referrer, device, bouncers, n_visit,
# n_pages, duration, country, purchase), from the local data/web.csv snapshot.
web_path <- if (file.exists("data/web.csv")) "data/web.csv" else "https://raw.githubusercontent.com/rsquaredacademy/datasets/master/web.csv"
ecom <- readr::read_csv(web_path, show_col_types = FALSE)
ecom <- dplyr::select(ecom, referrer, device, bouncers, n_visit, n_pages, duration, country, purchase)
con <- DBI::dbConnect(RSQLite::SQLite(), ":memory:")
dplyr::copy_to(con, ecom)

4.3 Aggregate

Let us combine the aggregate statements with WHERE statement to filter data.

  • SUM() : returns the total sum of a numeric column
SELECT SUM(n_visit) FROM ecom
1 records
SUM(n_visit)
4972 
SELECT SUM(n_visit) 
FROM ecom 
WHERE n_visit > 5
1 records
SUM(n_visit)
3574
  • AVG() : returns the average value of a numeric column
SELECT AVG(n_visit) FROM ecom
1 records
AVG(n_visit)
4.972 
SELECT AVG(n_visit) 
FROM ecom 
WHERE country LIKE 'P%'
1 records
AVG(n_visit)
5.079137
  • MAX() : returns the largest value of the selected column
SELECT MAX(n_visit) FROM ecom
1 records
MAX(n_visit)
10 
SELECT MAX(n_visit) 
FROM ecom 
WHERE device = 'tablet'
1 records
MAX(n_visit)
10
  • MIN() : returns the smallest value of the selected column
SELECT MIN(n_visit) FROM ecom
1 records
MIN(n_visit)
0 
SELECT MIN(n_visit) 
FROM ecom 
WHERE duration BETWEEN 600 AND 900
1 records
MIN(n_visit)
0

4.4 Alias

SQL aliases are used to give a table, or a column in a table, a temporary name. They are often used to make column names more readable. An alias only exists for the duration of the query. Below are a few examples:

SELECT AVG(n_visit) AS avg_mobile 
FROM ecom 
WHERE device = 'mobile'
1 records
avg_mobile
5.479651 
SELECT MAX(n_visit) AS max_visit 
FROM ecom
1 records
max_visit
10 
SELECT MIN(duration) AS min_duration 
FROM ecom
1 records
min_duration
10

4.6 Group By

The GROUP BY statement is used with aggregate functions (COUNT, MAX, MIN, SUM, AVG) to group the result by one or more columns.

SELECT device, 
count(*) AS visits 
FROM ecom 
GROUP BY device 
ORDER by visits DESC
3 records
device visits
mobile 344
tablet 331
laptop 325 
SELECT device, MAX(duration) AS max_duration 
FROM ecom 
GROUP BY device 
ORDER by max_duration DESC

laptop 997

4.7 Exercises

  1. Compute the average pages per visit (AVG(n_pages)) for each referrer, ordered highest average first. Which referrer tops the list?
  2. What is the longest duration among visits that made a purchase (purchase = 1)?
  3. Among mobile visits only, count visits by country and show the top 5. Which country is first?
Solutions

  1. SELECT referrer, AVG(n_pages) AS avg_pages FROM ecom GROUP BY referrer ORDER BY avg_pages DESC — direct (~6.38) tops the list.

  2. SELECT MAX(duration) FROM ecom WHERE purchase = 1 — 580.

  3. SELECT country, COUNT(*) AS visits FROM ecom WHERE device = 'mobile' GROUP BY country ORDER BY visits DESC LIMIT 5 — China (53) is first.
